# ชุดนำเสนอ Portfolio — Ash & Oak Barber Booking

สไลด์ 8 ภาพ (16:9, 1920×1080) + วิดีโอ + PDF เล่าเรื่อง "ก่อน → หลัง" ว่าระบบช่วยเจ้าของร้านและลูกค้าตรงไหน ทุกภาพของแอปจับจากเดโมที่ใช้งานได้จริง

## ไฟล์ไหนใช้ทำอะไร

| ไฟล์ | ใช้เมื่อ |
|---|---|
| `slides/01.png` – `08.png` | โพสต์ใน portfolio / เว็บ / โซเชียล ทีละภาพ |
| `deck.pdf` | ส่งให้ลูกค้าอ่านหรือแนบอีเมล (8 หน้า) |

| `source/` | ต้นฉบับ HTML/CSS/ภาพจากแอป/ฟอนต์ แก้ข้อความแล้ว render ใหม่ได้ |

วิดีโอไม่มีเสียงพูดและเพลง

## เรื่องที่เล่าในสไลด์

1. ปก
2. **ก่อน:** คิวกระจายในแชต กระดาษ ความจำ (ภาพแชตเป็นภาพจำลองสถานการณ์ ติดป้ายไว้ในภาพ)
3. **หลัง (ลูกค้า):** จองเอง 4 ขั้นตอน ได้ Reference code
4. **หลัง (เจ้าของ):** Today + Needs action + รับคำขอในแถวเดียว
5. **ก่อน → หลัง:** ปัญหาแต่ละข้อ ระบบช่วยตรงไหน
6. **ช่วยได้มากแค่ไหน:** ตัวเลขที่วัดจากเดโม
7. มือถือ เดสก์ท็อป ไทย/อังกฤษ
8. ปรับให้เข้ากับร้าน และขอบเขตของเดโม

## ตัวเลขในสไลด์มาจากไหน (วัดตอนอัดวิดีโอ)

| ตัวเลข | วิธีวัด | ผล |
|---|---|---|
| ลูกค้าจองครบ 6 แตะ | นับ click event จริงในหน้าจองตั้งแต่เลือกบริการจนส่งคำขอ (จองวันนี้ ไม่รวมพิมพ์ชื่อ/เบอร์) | 6 (เลือกวันอื่น +1 = 7) |
| เจ้าของรับคำขอ 1 แตะ | นับ click event ฝั่งเจ้าของจากปุ่ม Accept ในรายการ | 1 และสถานะเป็น confirmed |
| เวลาที่ถูกจองหายจากตัวเลือก | อ่านรายการเวลาของลูกค้าคนถัดไปก่อน/หลังมีคนจอง 14:00 (Haircut 45 นาที) | ก่อน 14:00, 14:30, 19:00 → หลัง 19:00 |
| ชุดทดสอบ 19 ข้อ | `npx vitest run` | ผ่านทั้งหมด |
| 6 สถานะ, 2 ภาษา | นับจากโค้ด/UI | 6 และ EN/TH |

## สิ่งที่ชุดนี้ไม่ได้บอก

- **ไม่มีตัวเลขรายได้ เวลาที่ประหยัด หรืออัตรา no-show ของร้านจริง** เพราะเดโมนี้ยังไม่มีผู้ใช้จริง สไลด์ 6 ระบุไว้บนภาพและแนะนำตัวชี้วัด 3 ตัวสำหรับวัดหลังใช้งานจริง
- ภาพแชตในสไลด์ 2 เป็นภาพจำลอง ไม่ใช่ข้อมูลของร้านใด
- ชื่อร้าน บริการ ราคา และลูกค้าในภาพเป็นข้อมูลตัวอย่างสมมติ (เวลาในภาพล็อกเป็นวันจันทร์ 12 ต.ค. 11:10 เพื่อให้ผลซ้ำได้)
- ไม่มีช่องทางติดต่อบนสไลด์ เพราะยังไม่มีข้อมูล ให้เพิ่มเองในสไลด์ 8 (`source/slides.html`) แล้ว render ใหม่
- เดโมเก็บข้อมูลในเบราว์เซอร์ ยังไม่มีล็อกอิน ฐานข้อมูลกลาง SMS/LINE หรือการชำระเงิน (ระบุไว้ในสไลด์ 8)

## ตรวจแล้ว / ยังไม่ได้ตรวจ

- ตรวจแล้ว: PDF 8 หน้า (render กลับเป็นภาพแล้วดูครบ), วิดีโอ decode ตลอดไฟล์ และดูภาพกลางแต่ละฉาก + ฉากเฟด, ฟอนต์โหลดครบ, ไม่มีภาพแตก
- ยังไม่ได้ตรวจ: เสียง (ไม่มี), การเล่นบนเครื่องเล่นอื่นนอกจาก ffmpeg/Chromium, การพิมพ์จริง, ให้ผู้ตรวจอิสระเปิดดูสไลด์

## ทำสไลด์ใหม่

เปิด `source/slides.html` ผ่าน static server (ใช้ path แบบ relative) ที่ viewport 1920×1080 แล้วถ่ายทีละ `#s1`–`#s8`; คลิปใช้งานจริงมาจาก `source/stage.html` ที่ฝังแอปสองจอ ภาพแอปใน `source/shots/` จับจากแอปที่ build จากโค้ดปัจจุบัน
